DHINESH K - PERSONAL PORTFOLIO

Website: https://dhinesh-xo.github.io/
Repository: https://github.com/Dhinesh-XO/Dhinesh-XO.github.io

This is a standalone static website. It does not require ChatGPT, Codex,
an API key, an installation, or a build step to run.

LOCAL VIEWING
Open index.html in a browser, keeping the assets folder beside it.
For a local web server, run from this folder:
  python -m http.server 4173 --bind 127.0.0.1
Then open http://127.0.0.1:4173. Press Ctrl+C to stop the server.
The local address is only available on this computer.

EDITING
Edit content.js for experience, projects, research, and image paths.
Edit index.html for section markup, styles.css for appearance,
and app.js for page rendering. Photographs and logos are in assets/images.
Keep image aspect ratios and descriptive alternative text.

PUBLISHING UPDATES
GitHub Pages publishes the main branch from the repository root.
Commit and push your changes to main. GitHub Pages will update the same URL.
Keep .nojekyll in the repository so the files are published as supplied.
